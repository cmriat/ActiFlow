# goals · A：可观测的剩余目标验证

来源 VLA-Corrector 的可观测进展验证，适配为**逐目标完成集合的验证与撤销**：

- 输入：双视角 RGB + proprio + 原任务目标编码；输出：每目标当前完成概率。
- 完成状态**可撤销**——后续动作破坏的目标不能被"曾经完成"永久锁住。
- 推理期禁止谓词、未来状态、任务成功 flag、episode ID、计时器。
- 低置信度回退已冻结 FIXED160 规则；选择器记录每次切换原因。
- 训练标签可来自 sim 谓词；val/confirmation 不得参与训练。

详细方案见 `docs/plan/02-final-ab.md`。
