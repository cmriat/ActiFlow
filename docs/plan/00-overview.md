# 00 · 总览：RSI + embodied WAM 的最终 A+B

## 背景一句话

完整语言策略已能完成局部动作，但长任务中**何时继续、何时切换目标**会出错。
FIXED160（固定时钟切换）已有实证收益，oracle 切换在 dev 仍更好 →
下一步是学习判断与检验动作后果，而非复活已证伪的方向。

## 系统组成

- **主交付模型（世界模型）**：`W(x_initial, x_history, commanded_actions) → future_video`。
  动作是输入，输出是未来视频；动作输出头不做。见 [01](01-wan-action-model.md)。
- **A · 可观测剩余目标验证**：逐目标完成概率估计（可撤销），替代固定时钟。
  来源 VLA-Corrector 的可观测进展验证；不声称概念首创（AGM 等有先例）。
- **B · 动作条件后果预测**：同状态下比较"继续当前子目标 / 切换下一子目标"的短程后果。
  来源公开的动作条件视频预测工作；其原生双动作路径本身不是创新，创新点是决策层适配。

## 交付边界（诚实声明）

- 结构为公开双路径动作条件结构的 Wan2.2 适配，**不声称原创网络结构**；不声称复现任何未公开核验的变体。
- 带 oracle 教师的 SFT **不能**描述为自主 RSI。
- 14D（RoboTwin）与 7D（LIBERO/Cosmos）动作空间不同，**跨平台结果不能拼接宣称联合有效**；
  联合只在 7D 桥接实测通过后成立。
- 任何候选未过门：交付 14D 动作输入模型 + 已验证控制器（FIXED160）+ A 诊断，
  并写明"A+B 联合主张未成立"。

## 部署形态

`FIXED160`（回退）→ `A-only`（有稳定增益时）→ `A+B`（桥接验收 + 超过计算对照时）。
最终只确认一个候选对最强对照；若 A-only 与 A+B 持平选 A-only，FIXED160 更好则交付 FIXED160。
