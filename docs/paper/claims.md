# 论文主张边界（可以说 / 不能说）

按最终证据选择标题与主张，三档：

1. **只有现有控制收益** → 目标分解的实证与可复用控制基线。
2. **加上动作模型** → 公开双路径结构的 Wan2.2 动作条件适配与严格干预验证；控制结果单列应用背景。
3. **A+B 同平台超过强对照** → 可观测目标验证与动作后果预测联合改进长任务执行；
   必须承认层次控制、完成估计、模型预测控制等先例，具体增量由消融说明。

## 不能说

- 不把公开结构基座的改造称为原创 A+B；不声称复现任何未公开核验变体的速度/分数。
- 不把带 oracle 教师的 SFT 描述为自主 RSI。
- 不主张已满足 CVPR oral、多轮 RSI 或异构能力泛化。
- 未见组合只在真正未用于训练/选型的组合上另测；不为凑项随机换组合。
- 14D 与 7D 两平台的单独好数字不能拼接宣称联合有效。
